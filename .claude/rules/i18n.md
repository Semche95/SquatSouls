# Languages

- No visible text hardcoded in the interface: every text goes through `t`, and every key is added to every language, `src/locales/en.json` and `src/locales/fr.json`, with named placeholders and plurals rather than concatenated pieces. Rust holds no translated text: it returns error codes with their parameters (`AppError`), and the tray and notification texts come from the interface.
- A new language starts from the schemas (`src/locales/schema.json`, `site/locales/schema.json`, the `languages` of `src-tauri/src/app/config/seed.schema.json`), never from another language's file. Any change of structure (key, placeholder, plural, seed or catalog field) goes into its schema in the same change; `schemas.test.js` checks every language file and every file of the seed and the catalog against it, and the backend tests check `seed.schema.json` and `catalog/schema.json` against the configuration structures and limits.
- Texts in every language speak to everyone: no gendered word.
- Each language is written the way it is naturally said, not translated word for word: the French and English versions of a text may differ in structure as long as they say the same thing (for example a statement in French, "Par défaut, celle de tous les exercices.", and an instruction in English, "Leave blank to use the general recovery.").
